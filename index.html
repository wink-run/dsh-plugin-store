    关于这个商店

    数据来源

    目录来自 GitHub 话题 dsh-plugin：每 3 小时用 GitHub Search API 抓取全部打上该话题的公开仓库，并整理出类别、简介与安装命令。

    安装方式

    每个插件的详情页都带一条可直接执行的命令（dsh plugin --profile web add … 或 npm 包），复制到终端即可。没有 DeepSeek Harness？先 npm install -g @deepseek-ai/dsh。

    安全提示

    本商店只做索引与发现，不托管也不审查插件代码。安装第三方插件会运行其源码，请先阅读仓库、检查许可证，并在隔离环境中试用。

    加入生态

    你的插件也想被收录？给仓库打上 dsh-plugin 话题即可，下次抓取自动出现。也可以提交到社区精选列表 awesome-dsh-plugin。

    DSH Store

    一个社区项目，与 DeepSeek 官方无隶属关系。数据抓取自 GitHub，内容版权归各仓库作者所有。
